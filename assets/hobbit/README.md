# assets/hobbit

16x16 item sprites copied from the VoxelHobbit project's converted assets
(the 1.7.10 LOTR mod: body*, sword*, ... ; vanilla Minecraft: chainmail_chestplate,
iron_chestplate, bow_*, arrow, flint). Not free art: Mojang's and the LOTR mod's.
mktiles.py maps them to the game's armour and weapon names (gear.rec).

skin.png is the hero's skin (the CustomNPCs Boromir, 64x32) and armor/
the armour layer textures the inventory's hero wears (<set>_1.png and
_2.png; hud.go's armorSets names each armour kind's set), copied from
the same place.
